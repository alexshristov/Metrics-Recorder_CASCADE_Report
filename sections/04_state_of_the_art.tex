\subsection{Deting Inconsistencies}

Testing source code and its documentation on its consistency has long been an important topic in software engineering.
The recent advances of LLM's has created the possibility for a number of new approaches. 
One of these aproaches is DocChecker. 
It uses a pre-trained language model to identify and correct inconsistent comments.
Another related aproach is C4RLLaMA, which also compares comments with code with its fine tuned model based on the open source model CodeLLaMa.
These aproaches prior to CASCADE demonstrate, that LLM's can outperform traditional aproaches without LLM's.
